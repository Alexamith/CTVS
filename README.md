# Propuesta a CTVS · Gloz Studio

Página web estática con la propuesta de capacitación en publicidad digital, desarrollo de contenido y acompañamiento que Gloz Studio preparó para CTVS.

## Estructura

```
index.html        Contenido de la propuesta
css/estilos.css   Estilos (colores y letras de la marca Gloz en :root)
js/main.js        Animaciones ligeras, sin librerías
img/              Favicon, ícono para iPhone e imagen para compartir
```

## Editar

- Textos: directamente en `index.html`, una sección por bloque comentado.
- Colores y espacios: variables al inicio de `css/estilos.css`.
- Si cambias CSS o JS, sube el número `?v=` de su enlace en `index.html` para que el navegador no muestre la versión vieja guardada.

## Publicación

Se publica con GitHub Pages desde la rama `main`, carpeta raíz. La página tiene `noindex` para que no aparezca en buscadores; aun así, cualquiera con el enlace puede verla.
